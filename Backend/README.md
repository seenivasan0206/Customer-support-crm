
# Customer Support CRM - Backend

Python FastAPI backend for the Customer Support CRM application.

## Tech Stack
- Python
- FastAPI
- SQLite
- Django

## Installation

Create a virtual environment

```bash
python -m venv .venv
```

Activate environment

Windows
```bash
.venvScriptsactivate
```

MacLinux
```bash
source .venvbinactivate
```

Install dependencies

```bash
pip install -r requirements.txt
````


## Main Modules
- Authentication
- Support Requests
- Customer Management
- Agent Management
- Reports & Analytics
- Database Configuration
