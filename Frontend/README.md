
# Customer Support CRM - Frontend

React.js frontend for the Customer Support CRM application.

## Tech Stack
- React.js
- Vite
- CSS
- Axios
- React Router DOM

## Installation

```bash
npm install
```

## Run Development Server

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Available Screens
1. Login
2. Dashboard Overview
3. Support Requests
4. Customer Management
5. Conversations & Live Chat
6. Agents & Teams
7. Knowledge Base
8. Reports & Analytics
9. Settings & Administration
