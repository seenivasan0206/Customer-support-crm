
# Customer Support CRM

A full-stack Customer Support CRM built using React.js and Python FastAPI Django.

## Tech Stack
- Frontend: React.js, Vite, CSS
- Backend: Python, FastAPI, Django
- Database: SQLite

## Features
- Dashboard Overview
- Support Requests
- Customer Management
- Conversations & Live Chat
- Agent Management
- knowledge Base
- Reports & Analytics
- Settings & Administration
- User Login
